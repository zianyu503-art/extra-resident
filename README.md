# 多出來的住戶

第一人稱心理恐怖遊戲（原型，約 25 分鐘）。舊公屋九樓的夜班管理員，巡到 03:00 最後一班電梯——有個東西正在學習如何成為你。

**立即遊玩：<https://zianyu503-art.github.io/extra-resident/>**

- 電腦：WASD 移動、滑鼠看、E 互動、R 開鎖、F 拍照、Q 相簿、V 證據、Tab 巡更打卡器、Esc 暫停
- 手機／平板：左下搖桿移動、右半邊拖動轉視線、右下按鈕互動；建議橫向
- 建議戴耳機；重要聲音都有字幕；暫停選單有舒適設定

本倉庫只有網頁版檔案（Godot 4.6 匯出）。
